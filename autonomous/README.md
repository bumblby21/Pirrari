# autonomous: 학습된 모델로 Raspbot 주행하기

`model_1`에서 학습한 **`best.pt` 하나**를 선택하면 실시간 카메라 영상으로 방향을 예측하고
Raspbot 모터를 제어합니다. 실행할 때 학습 데이터셋은 필요하지 않습니다.
`Pirrari/model_1`의 모델 정의/추론 코드도 함께 있어야 하므로 프로젝트 폴더를 유지하세요.
다른 구조로 만든 임의의 `.pt` 파일은 지원하지 않습니다.

## 준비

- Raspbot, 카메라, 기존 컬렉터와 같은 `Raspbot_Lib` 설치 환경이 필요합니다.
- 카메라 각도와 조명, 주행 환경은 학습 데이터와 맞추세요.
- 컬렉터와 자율주행 프로그램을 동시에 실행하지 마세요. 카메라와 모터를 함께 사용합니다.
- 현재 Pi에서는 `/home/pi/yolov5-lite/bin/python`을 사용합니다.
- 이 가상환경에서 드라이버를 찾지 못하면 기존 `~/py_install/Raspbot_Lib` 소스를 불러옵니다.
- 새 환경은 `python -m pip install -r autonomous/requirements.txt`로 Python 의존성을 설치하고,
  로봇 제공 `Raspbot_Lib`와 I2C 접근 환경도 준비해야 합니다.

## 1. 모델 넣기

학습 결과 중 원하는 모델을 복사합니다. 다음 경로의 `<실행시간>`은 실제 학습 폴더명으로 바꾸세요.

```bash
cd /home/pi/Pirrari
cp model_1/runs/<실행시간>/best.pt autonomous/models/best.pt
```

또는 복사하지 않고 아래 실행 명령에 `--model /원하는/경로/best.pt`를 추가해도 됩니다.
학습이나 모델 선택을 자동으로 수행하지 않습니다.

## 2. 카메라 예측 확인 (모터 미사용)

```bash
cd /home/pi/Pirrari
/home/pi/yolov5-lite/bin/python autonomous/drive.py
```

실시간 예측과 확률을 터미널에 출력합니다. 이 모드에서는 `Raspbot_Lib`를 불러오지 않고
모터 명령도 보내지 않습니다. 이미 다른 프로그램으로 움직이는 로봇을 정지시키는 모드는 아닙니다.

## 3. 실제 주행

```bash
cd /home/pi/Pirrari
/home/pi/yolov5-lite/bin/python autonomous/drive.py --drive
```

기본 전진 속도는 28, 회전 속도는 25로 컬렉터와 같습니다.
모델을 바꾸면 다시 학습할 필요 없이 파일만 교체하거나 `--model` 경로를 바꾸면 됩니다.

```bash
/home/pi/yolov5-lite/bin/python autonomous/drive.py \
  --model /원하는/경로/best.pt --drive --duration 10
```

`--duration 10`은 약 10초 후 종료합니다. 기본값은 수동 종료까지 실행입니다.
**Space / X / Q / ESC / Ctrl+C**로 정지 후 종료하며 자동 재출발하지 않습니다.
실제 주행은 키보드 입력 가능한 터미널에서 실행해야 합니다.

## 동작과 정지 조건

- 카메라 0번에서 320×240 영상 요청 → 32×32 RGB 변환 → 최근 5프레임 → 모델 예측 순서입니다.
- 컬렉터와 같은 10Hz를 목표로 실행합니다. 실제 속도는 카메라와 추론 시간에 따라 달라집니다.
- 액션 0=전진, 1=제자리 우회전, 2=제자리 좌회전입니다.
- 처음 5프레임이 모일 때까지 정지합니다.
- 예측 최대 확률이 기본 0.6 미만이면 정지합니다. 이후 확률이 높아지면 다시 움직일 수 있습니다.
  `--min-confidence`로 변경할 수 있지만, 확률은 안전을 보증하는 점수가 아닙니다.
- 카메라 실패, 잘못된 예측값, 예외, SIGINT/SIGTERM/SIGHUP, 키보드 종료 시 정지합니다.
- 독립된 소프트웨어 감시 스레드가 마지막 영상 시각 기준 기본 0.5초 동안 명령이 갱신되지 않으면
  정지를 요청하고 재출발을 막습니다. `--timeout`은 0.1~2초 범위입니다.
- SSH 실행 시 `/proc/net/tcp`, `/proc/net/tcp6`에서 현재 SSH 연결을 0.2초 간격으로 확인합니다.
  ping 응답이나 ICMP 방화벽 설정은 필요하지 않습니다. 연결 종료/소멸 또는 반복 재전송 실패 시 정지합니다.
  0.2초는 확인 주기이며 단절 감지 시간 보장은 아닙니다. 무선 단절을 커널이 인식하기까지 지연될 수 있고,
  SIGHUP/터미널 종료 감지도 함께 사용합니다. 오래된 SSH 환경변수가 남은 tmux 등의 세션에서는
  새 SSH 터미널에서 직접 실행하세요.

이 모델은 **방향 모방 모델**로 장애물 감지나 도로 안전 판단을 제공하지 않습니다.
실제 주행은 먼저 바퀴를 띄워 방향을 확인한 뒤 작은 테스트 공간에서 확인하세요.
카메라 드라이버 내부에서 반복되는 영상, 프로세스 강제 종료(SIGKILL), OS 정지,
I2C 호출 자체의 멈춤은 소프트웨어 감시만으로 정지를 보장할 수 없습니다.
또한 제공된 `Raspbot_Lib`는 일부 I2C 오류를 출력만 하고 숨기므로 모든 통신 실패를 실행 코드가 감지할 수는 없습니다.
